# 整数分拆子和多项式倒数和的分母对数凹性

本仓库收录一份计算机辅助证明稿，研究 Ballantine、Beck、Feigon 与 Maurischat 的第 4 猜想。猜想断言，分拆子和多项式倒数和的分母系数序列，恰在参数为 3、5、6、7 时不对数凹。稿件给出了覆盖所有正整数参数的论证，尚待独立同行复核。[原论文](https://doi.org/10.1007/s11139-026-01419-0) · [阅读证明稿（PDF）](proof.pdf) · [可编辑正文](proof.html)

## 复算

在仓库根目录使用 Python 3.11 运行以下命令。三个程序仅依赖标准库。

```sh
python check_denominator.py 1024
python check_edge.py 4096
python verify_transition.py --witnesses reproduced-boxes.csv
```

第一条检查所有不超过 1024 的参数，预期比较 119,653,461 个系数位置，得到上述四个例外。第二条核验端部卷积归纳所需的有限前提。第三条以有理数和向外取整的界验证过渡区域，预期覆盖 2,348 个终端区间，其中 998 个通过积分判据。

最后一条命令重新生成证书，便于与仓库中的原始证书比较。每行给出一个参数区间，积分判据两项上界的单位均为百万分之一。[逐区间证书](boxes.csv)
